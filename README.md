# 欧陆时序 · Chronica Europae

An interactive historical atlas of Europe, 500 BC – present. Drag the timeline to watch borders change, click any city to read its name history and events, follow nine historical journeys, and test yourself with the place-name quiz. Interface in 简体中文 / 繁體中文 / English / Deutsch / Français / Español.

Static site: no build step. Serve the folder with any static host (Vercel, Netlify, GitHub Pages, nginx).

## Data sources
- Historical polity outlines: [aourednik/historical-basemaps](https://github.com/aourednik/historical-basemaps) (GPL-3.0), clipped to Europe and simplified.
- Land, rivers and lakes: [Natural Earth](https://www.naturalearthdata.com/) (public domain).
- Inspired by [江山时序 Jiangshan Atlas](https://github.com/DeanChensj/jiangshan-map).

Historical borders are schematic approximations, not surveyed boundaries.
